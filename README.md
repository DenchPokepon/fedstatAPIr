# fedstatAPIr

[English](README.en.md)

Пакет для R, который скачивает данные [ЕМИСС Росстата](https://www.fedstat.ru):
выбираете показатель и фильтры — получаете таблицу. Экономит ⏳ и нервы 😡.
Пакет неофициальный.

## Установка

```r
install.packages("fedstatAPIr")
```

Самая свежая версия — с GitHub:

```r
# install.packages("remotes") # если remotes ещё не установлен
remotes::install_github("DenchPokepon/fedstatAPIr")
```

## Быстрый пример

Скачаем [индексы потребительских цен (показатель 31074)](https://www.fedstat.ru/indicator/31074)
за январь 2024 года по Приморскому краю: все товары и услуги, к предыдущему
месяцу и к январю прошлого года.

Номер показателя берём из адреса страницы, названия фильтров и значений — с самой
страницы. Скопируйте код в R или RStudio и выполните целиком:

```r
library(fedstatAPIr)

filters <- list(
    "Год" = "2024",
    "Период" = "Январь",
    "Классификатор объектов административно-территориального деления (ОКАТО)" = "Приморский край",
    "Виды показателя" = c(
        "К предыдущему месяцу",
        "К соответствующему периоду предыдущего года"
    ),
    "Виды товаров и услуг" = "*" # звёздочка — все значения
)

job <- fedstat_download(
    indicator_id = "31074",
    filters = filters,
    cache_dir = "ipc-download" # папка для скачанных частей
)
data <- fedstat_collect(job) # готовая таблица
```

Получится таблица `data` из 1 500 строк: 750 товаров и услуг × 2 вида индекса.
Так выглядят первые строки главных столбцов (настоящие данные ЕМИСС):

```r
head(data[c("s_grtov", "s_POK", "ObsValue")], 5)
#>                              s_grtov                                       s_POK ObsValue
#> 1                Все товары и услуги                        К предыдущему месяцу   100.72
#> 2                Все товары и услуги К соответствующему периоду предыдущего года   109.31
#> 3                         Все товары                        К предыдущему месяцу   100.87
#> 4                         Все товары К соответствующему периоду предыдущего года   109.81
#> 5 Базовый индекс потребительских цен                        К предыдущему месяцу   100.81
```

* `ObsValue` — значения показателя, уже числами.
* Остальные столбцы ЕМИСС называет своими кодами: здесь `s_grtov` — товары и
  услуги, `s_POK` — вид индекса, `s_OKATO` — территория. `Time` — год, `PERIOD` —
  период, `EI` — единица измерения. В столбцах `..._code` — коды классификаторов.
* Папка `ipc-download` появится в текущей папке R (в проекте RStudio — в папке
  проекта). Можно указать и полный путь, например `"G:/research/ipc-download"`.
  Если `cache_dir` не указать, пакет сам создаст папку вида `fedstat-31074-1a2b3c4d`
  и напишет, где она. Для тех же фильтров это всегда та же папка.

Про фильтры:

* несколько значений — через `c()`: `"Год" = c("2023", "2024")`;
* `"*"` выбирает все значения фильтра;
* фильтр, у которого на сайте больше одного значения, нужно указать обязательно.
  Если забудете, пакет назовёт его в ошибке;
* регистр букв и лишние пробелы не важны.

## Почему скачиваем по частям 🧩

ЕМИСС строит таблицу из всех сочетаний выбранных значений. 20 лет × 12 месяцев ×
90 регионов × 1 000 товаров — это 21,6 миллиона сочетаний. Пусть большинство из
них пустые, ЕМИСС всё равно проверяет каждое. Такой запрос часто зависает или
обрывается, а заодно замедляет сайт для всех остальных.

`fedstat_download()` режет запрос на небольшие части, делает паузы между ними и
сохраняет каждую готовую часть на диск. ЕМИСС получает лёгкую и ровную нагрузку,
а вы — загрузку, которая доходит до конца и продолжается с места остановки.

Пример выше — около 2 200 сочетаний, это всего один запрос. Части нужны для
выборок побольше: по умолчанию в одной части до 50 000 сочетаний, а между
запросами пауза 30–60 секунд.

Запрос больше 100 000 сочетаний пакет без особой настройки не отправит, а больше
250 000 — не отправит никогда, какой бы функцией вы ни пользовались. Такие запросы
почти никогда не удаются, а сайт тормозят всем. `fedstat_download()` скачает ту же
выборку частями.

## Если загрузка остановилась 🔁

Запустите тот же код ещё раз — с теми же фильтрами и той же `cache_dir`.
Готовые части пропускаются, скачиваются только оставшиеся. Это работает и после
перезапуска R или компьютера.

На один запуск отводится час, включая паузы. Чтобы дать два часа, добавьте в
вызов `fedstat_download()` строку `total_time_limit_seconds = 7200`.

Проценты в сообщениях — доля обработанных сочетаний, а не оставшееся время.

Готовую загрузку можно открыть позже, даже без интернета:

```r
data <- fedstat_collect("ipc-download")
```

Одна папка — одна выборка: для других фильтров укажите другую `cache_dir`.

## Что видите → что делать

Сообщения пакета — на английском. Ищите в таблице начало сообщения.

| Сообщение | Что случилось | Что делать |
| --- | --- | --- |
| `Download time limit reached` | Закончился час на запуск | Запустите тот же код ещё раз |
| `Automatic recovery stopped` | ЕМИСС не отвечает или отвечает ошибками | Подождите час-другой и запустите тот же код ещё раз |
| `Fedstat may be checking or restricting access`, `Fedstat refused access` | ЕМИСС ограничивает доступ | Пакет сам выждет паузу. Если загрузка остановилась, проверьте, открывается ли www.fedstat.ru в браузере, и повторите позже |
| `This download folder is in use by another R session` | С папкой уже работает другая сессия R | Дождитесь её. Если R закрылся с ошибкой, удалите папку `.lock` — путь к ней есть в сообщении |
| `Fedstat changed the filters`, `Fedstat returned data for values that were not requested` | ЕМИСС изменил фильтры показателя | Начните заново с новой `cache_dir` |
| `Fedstat renamed some values`, `Fedstat no longer offers some of the values you selected` | ЕМИСС переименовал или убрал отдельные значения | Ничего, загрузка продолжится. Убранные значения покажет `print(job)` |
| `Some ObsValue values are not numbers` | В данных есть пометки вместо чисел | `fedstat_collect(job, try_to_parse_ObsValue = FALSE)` вернёт значения текстом |
| `This request has ... filter combinations` | Запрос слишком велик для одного обращения к ЕМИСС | Скачайте через `fedstat_download()` — он разделит выборку на части |
| `Unknown argument` | Опечатка в названии настройки | Сверьте написание с `?fedstat_download` |

**Части раз за разом не скачиваются?** Добавьте в вызов `preview_first = TRUE`.
Тогда перед каждой частью пакет сначала просит ЕМИСС показать таблицу — как кнопка
«Применить» на сайте — и только потом скачивает её. Иногда ЕМИСС отдаёт данные
только так. Загрузка станет примерно вдвое дольше. Включить можно и посреди
загрузки, в той же папке.

## Большие выгрузки

* `filters = "*"` вместо списка выбирает всё: все годы, территории и остальные
  значения. Это может занять много часов.
* `max_nominal_cells_request` — размер части в сочетаниях, по умолчанию 50 000.
  Больше обычно хуже: выше 50 000 пакет предупредит, выше 100 000 нужна
  настройка `allow_large_requests = TRUE`, а больше 250 000 нельзя.
* `timeout_seconds = 300` — ждать ответа на запрос до 5 минут вместо 3.
* `fedstat_collect()` загружает всю таблицу в память.

Все настройки и подробности — в справке `?fedstat_download`.

## Освободить место

Части сами не удаляются. Сохраните таблицу, потом удалите их:

```r
saveRDS(data, "ipc-2024.rds") # сохранить таблицу
fedstat_cleanup(job)          # удалить скачанные части
```

Сохранённая таблица откроется командой `data <- readRDS("ipc-2024.rds")`.

## Как найти показатель

Номер показателя — в адресе его страницы на fedstat.ru. В пакете есть и список
показателей (на момент выхода версии), номер — в столбце `id`:

```r
ind <- fedstat_indicators_names_database
ind[grepl("потребительских цен", ind$title), c("id", "title")]
```

Свежий список скачает `fedstat_indicator_info()`.

## Для опытных пользователей

`fedstat_get_data_ids()`, `fedstat_data_ids_filter()`,
`fedstat_post_data_ids_filtered()` и `fedstat_parse_sdmx_to_table()` — отдельные
шаги одного запроса, без деления на части и пауз. Функция
`fedstat_data_load_with_filters()` из версии 1.x работает, но устарела. Для них
действуют те же ограничения размера запроса.
