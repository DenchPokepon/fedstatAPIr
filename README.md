# fedstatAPIr

[English](README.en.md)

fedstatAPIr — неофициальный пакет для загрузки данных
[ЕМИСС Росстата](https://www.fedstat.ru) в R с заданными фильтрами.

Пакет позволяет сэкономить ⏳ и нервы 😡: повторяет неотвеченные запросы,
делит большие выгрузки на части и сохраняет уже скачанное.
Если ЕМИСС снова решил отдохнуть, после перезапуска не придётся начинать с нуля.

## Установка

Выпущенную версию можно установить из [CRAN](https://CRAN.R-project.org/package=fedstatAPIr):

```r
install.packages("fedstatAPIr")
```

Версию разработки — из GitHub:

```r
# install.packages("remotes")
remotes::install_github("DenchPokepon/fedstatAPIr")
```

Примеры ниже используют новую функцию `fedstat_download()` из версии
1.1.0.9005 или новее. Если Вы устанавливаете пакет из скачанной папки
с исходниками, выполните в ней `R CMD INSTALL .`.

## Загрузка данных

Загрузим индексы потребительских цен за январь 2024 года по Приморскому краю:
к предыдущему месяцу и к соответствующему периоду прошлого года, по всем товарам
и услугам.

Возьмём номер показателя — **31074** — из
[адресе его страницы](https://www.fedstat.ru/indicator/31074).
Названия фильтров и их значений берутся с той же страницы.

```r
library(fedstatAPIr)

job <- fedstat_download(
  indicator_id = "31074",     # Индексы потребительских цен
  path = "ipc-primorye-2024", # Папка для данных; создаётся автоматически
  filters = list(
    "Год" = "2024",
    "Период" = "Январь",
    "Классификатор объектов административно-территориального деления (ОКАТО)" = "Приморский край",
    "Виды показателя" = c(
      "К предыдущему месяцу",
      "К соответствующему периоду предыдущего года"
    ),
    "Виды товаров и услуг" = "*" # Все товары и услуги
  )
)

# Собираем скачанные части в одну таблицу.
data <- fedstat_collect(job)
head(data)
```

Чтобы выбрать несколько лет, замените `"2024"` на `c("2023", "2024")`.
Звёздочка `"*"` выбирает все значения поля. Все поля с несколькими значениями
нужно указать явно: если что-то пропущено, пакет подскажет название поля в ошибке.
Регистр букв и лишние пробелы значения не имеют.

Посмотреть доступные фильтры можно и в R:

```r
filters_table <- fedstat_get_data_ids("31074")
View(filters_table[c("filter_field_title", "filter_value_title")])
```

В таблице результата `ObsValue` содержит исходные значения, включая десятичные
запятые и пометки вроде `...`. Столбцы с окончанием `_code` содержат коды
классификаторов. Значения сохраняются текстом, без автоматического преобразования
пометок источника в пропуски.

## Продолжение загрузки

**По умолчанию на один запуск отводится час.** Паузы и повторные попытки
тоже входят в этот час. Когда время заканчивается, пакет останавливает загрузку
и сохраняет прогресс. Уже полученные данные он успевает проверить и записать,
поэтому завершение может занять немного дополнительного времени.

Чтобы дать загрузке два часа, добавьте `time_limit_seconds = 7200` в вызов.
Каждый повторный запуск получает новый час (или указанное Вами время).

Если загрузка прервалась, просто запустите тот же код ещё раз, сохранив фильтры
и путь к папке.
Уже скачанные части будут проверены и пропущены. Это работает и после перезапуска R.
Когда загрузка закончилась, таблицу можно открыть по пути к папке:

```r
data <- fedstat_collect("ipc-primorye-2024")
```

В папке останутся журнал `download.log`, файл состояния `manifest.rds` и
скачанные таблицы в `parts/`. Сохраните её, если планируете продолжать загрузку
или работать с результатом позже.

Для другой выборки задайте новый `path`. Например, на Windows можно использовать
`"G:/research/ipc-2024"`. `fedstat_collect()` загружает результат целиком в память;
для очень больших выборок читайте отдельные части через `readRDS()`.

## Почему загрузка идёт по частям

Запрос к ЕМИСС задаёт комбинации фильтров. Например, 20 лет × 12 месяцев ×
90 территорий × 1000 товаров — это 21,6 миллиона возможных сочетаний.
Реальных наблюдений может быть гораздо меньше, но обработка запроса всё равно
может оказаться тяжёлой. Поэтому количество строк заранее не даёт надёжной
оценки размера запроса.

ЕМИСС пользуемся не только мы, поэтому постараемся не перегружать его большими
выгрузками. Пакет сам делит запрос на части и делает паузы по 30–60 секунд.
При временных сбоях он повторяет попытки, а если сервис долго не отвечает —
останавливается, сохранив полученные данные.

Для всей истории показателя можно передать `filters = "*"` вместо списка.
Это выберет все периоды, территории и прочие значения; такая загрузка может
занять много времени.

## Настройки

Обычно достаточно показателя, фильтров и папки. При необходимости в вызов
`fedstat_download()` можно добавить:

| Аргумент | Что меняет |
| --- | --- |
| `max_combinations = 500000` | До 500 тысяч сочетаний фильтров в одной начальной части. Это не число строк результата. По умолчанию — 100 тысяч. |
| `time_limit_seconds = 3600` | Один час на запуск, включая паузы и повторы. По умолчанию — 3600 секунд. |
| `timeout_seconds = 300` | Ждать один запрос до пяти минут, включая передачу файла. |
| `request_pause = c(30, 60)` | Ждать от 30 до 60 секунд между запросами. |

Увеличение `max_combinations` обычно уменьшает число частей новой загрузки,
но делает каждый запрос тяжелее для ЕМИСС. При продолжении уже созданные части
не объединяются обратно. Размер запроса и отведённое время выводятся при старте.

Другие настройки — повторные попытки, обновление токена, User-Agent и ограничения
соединения — описаны в `?fedstat_download` и [технической памятке](MIGRATION.md).

## Если что-то не работает

Приложите `download.log`, версию пакета и вывод `sessionInfo()` к
[сообщению об ошибке](https://github.com/DenchPokepon/fedstatAPIr/issues).
Журнал содержит этапы запросов, предупреждения и причины остановки; токены,
cookies и тела ответов в него не записываются.

HTTP 302 не позволяет однозначно отличить отказ сессии от проблемы выборки.
Пакет пробует обновить токен и уменьшить запрос, но не считает такой ответ
пустой таблицей. Если отказ повторяется, данные этой части остаются незагруженными.

Существующие функции, включая `fedstat_data_load_with_filters()`, продолжают
работать. Отдельные шаги получения фильтров, отправки запроса и разбора SDMX
доступны для собственных сценариев; примеры есть в справке каждой функции.
Каталог показателей доступен в `fedstat_indicators_names_database`.
