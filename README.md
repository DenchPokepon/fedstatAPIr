# fedstatAPIr

[English](README.en.md)

fedstatAPIr — неофициальный пакет для загрузки данных
[ЕМИСС Росстата](https://www.fedstat.ru) в R с заданными фильтрами.
Помогает сэкономить ⏳ и нервы 😡: выбираете показатель, годы, территории —
и получаете таблицу для работы.

## Установка

Из CRAN:

```r
install.packages("fedstatAPIr")
```

Или из GitHub:

```r
# install.packages("remotes") # Если remotes ещё не установлен
remotes::install_github("DenchPokepon/fedstatAPIr")
```

## Почему скачиваем по частям

ЕМИСС иногда долго отвечает или прерывает выгрузку. А фильтры перемножаются:
20 лет × 12 месяцев × 90 территорий × 1000 товаров — уже 21,6 миллиона
возможных сочетаний. Наблюдения есть не для каждого из них, но такой запрос
всё равно может оказаться тяжёлым.

`fedstat_download()` берёт эту работу на себя: скачивает небольшими частями,
делает паузы и повторяет неудачные попытки. Уже полученное сохраняется —
если ЕМИСС снова решил отдохнуть, начинать сначала не придётся.
Так удобнее нам и меньше нагрузка на сервис, которым пользуемся не только мы.

## Загрузка данных

Загрузим [индексы потребительских цен на товары и услуги — показатель 31074](https://www.fedstat.ru/indicator/31074)
за январь 2024 года по Приморскому краю. Выберем все товары и два вида индекса:
к предыдущему месяцу и к соответствующему периоду прошлого года.

Номер показателя берём из адреса страницы, названия фильтров — с самой страницы.

Скопируйте этот пример в R или RStudio и выполните его целиком:

```r
library(fedstatAPIr)

# Что хотим получить
filters <- list(
    "Год" = "2024",
    "Период" = "Январь",
    "Классификатор объектов административно-территориального деления (ОКАТО)" = "Приморский край",
    "Виды показателя" = c(
        "К предыдущему месяцу",
        "К соответствующему периоду предыдущего года"
    ),
    "Виды товаров и услуг" = "*" # Все товары и услуги
)

# Скачиваем: https://www.fedstat.ru/indicator/31074
job <- fedstat_download(
    indicator_id = "31074", # Индексы потребительских цен
    filters = filters,
    cache_dir = "ipc-download" # Рабочая папка для частей, чтобы продолжить при сбое
)

data <- fedstat_collect(job) # Собираем части в готовую таблицу
View(data)                   # Открываем таблицу в RStudio
```

Таблица для анализа — `data`. Рабочая папка `ipc-download` создаётся автоматически
в текущей папке R (в проекте RStudio — обычно в папке проекта).
Вместо короткого имени можно указать полный путь, например `"G:/research/ipc-download"`.

Для нескольких лет замените `"2024"` на `c("2023", "2024")`.
Звёздочка `"*"` выбирает все значения поля. Если забыли указать поле с несколькими
значениями, пакет подскажет его название. Регистр букв и лишние пробелы не мешают.

Значения показателя находятся в столбце `ObsValue`. Они сохранены текстом,
чтобы не потерять десятичные запятые и пометки источника вроде `...`.
Столбцы с окончанием `_code` содержат коды классификаторов.

## Продолжение загрузки

**По умолчанию на один запуск отводится час**, включая паузы и повторы.
Если время закончилось или соединение прервалось, запустите тот же вызов ещё раз
с прежними фильтрами и `cache_dir`, затем выполните `fedstat_collect(job)`.
Пакет продолжит с оставшихся частей. После закрытия и повторного открытия R
выполните пример целиком: уже скачанные части будут пропущены.

Каждый запуск получает новый час. Проверка и сохранение уже полученной
части могут немного продлить завершение. Как увеличить время — ниже.

Рабочую папку не удаляйте до окончания загрузки. Для другой выборки задайте
другую папку. Готовую таблицу можно открыть и позже:

```r
data <- fedstat_collect("ipc-download")
```

Проценты в сообщениях показывают обработанную долю выбранных сочетаний,
а не оставшееся время. Некоторые части содержат больше данных и скачиваются дольше.

## Если скачивание часто срывается

Повторите загрузку с дополнительной подготовкой, сохранив прежние фильтры и папку:

```r
job <- fedstat_download(
    indicator_id = "31074",
    filters = filters,
    cache_dir = "ipc-download",
    prepare_before_download = TRUE # Пакет сам применит фильтры перед скачиванием
)
data <- fedstat_collect(job)
```

Иногда ЕМИСС отдаёт файл только после предварительного запроса таблицы —
как при нажатии «Применить» на сайте. Эта настройка повторяет такой порядок
перед каждой попыткой скачивания. Поведение ЕМИСС меняется: в одних случаях
это помогает, в других ничего не даёт.

По умолчанию настройка выключена. Она добавляет второй запрос данных на каждую
попытку и может примерно удвоить время загрузки, включая паузы; точное время
зависит от ответов сервера. Включить её можно и при продолжении прежней загрузки.

Если для части сочетаний нет наблюдений, пакет проверяет это и продолжает работу.

## Размер запросов и ожидание

Обычно достаточно показателя, фильтров и рабочей папки. Если нужно больше времени,
добавьте `total_time_limit_seconds = 7200` внутрь вызова `fedstat_download()` —
это даст два часа вместо одного. Другие настройки добавляются так же:

| Аргумент | Что меняет |
| --- | --- |
| `max_nominal_cells_request = 100000` | До 100 тысяч сочетаний фильтров в запросе. Небольшие запросы обычно надёжнее, но вся загрузка может занять больше времени. |
| `total_time_limit_seconds = 3600` | Общий запас времени на один запуск: по умолчанию час. |
| `timeout_seconds = 300` | Дать отдельному запросу до пяти минут вместо трёх по умолчанию. |
| `request_pause = c(30, 60)` | Пауза между запросами: по умолчанию от 30 до 60 секунд. |

`max_nominal_cells_request` ограничивает **декартово произведение фильтров**:
число лет × месяцев × территорий × товаров × остальных выбранных значений.
Например, 2 × 12 × 10 × 100 = 24 000 номинальных ячеек, хотя реальных строк
может быть меньше. Большие части пакет делит дальше.

Начните со **100 000**, если важнее надёжность. Можно попробовать **250 000**,
но подходящий размер зависит от показателя и от того, как сейчас работает ЕМИСС.
Выше 250 000 пакет предупредит о риске сбоев.

Для всей истории показателя передайте `filters = "*"` вместо списка —
это выберет все годы, территории и прочие значения. Такая выгрузка может быть долгой.

## Когда рабочая папка больше не нужна

Сначала сохраните итоговую таблицу, затем удалите скачанные части:

```r
saveRDS(data, "ipc-2024.rds") # Сохранить таблицу для дальнейшей работы
fedstat_cleanup(job)         # Освободить место, занятое частями
```

Части сами не удаляются. Сохранённую таблицу можно открыть в другой сессии:
`data <- readRDS("ipc-2024.rds")`.

## Справка и помощь

`?fedstat_download` — все настройки, `?fedstat_collect` — сборка результата.
Она загружает таблицу целиком в память; работа с большими выборками и отдельными
шагами описана в [технической памятке](MIGRATION.md).

`verbose = FALSE` убирает сообщения о ходе работы, `verbose = "detailed"`
показывает подробности. При проблемах приложите `download.log` из рабочей папки
к [сообщению об ошибке](https://github.com/DenchPokepon/fedstatAPIr/issues).
Самостоятельно разбирать журнал не нужно. Также можно написать на
deniskrylovvit@gmail.com.
